# Martin Strategy

> **紧止损 + R 倍数记账** 的量化策略规格（规则层）
>
> 把「一笔交易能赚多少没法预测，能亏多少可以自己定」这个思路，重构为一套**可回测的量化规则**。
>
> 当前版本 **v2.0** ｜ 状态：**规则层完成，回测未开始**

---

## 这是什么

起点是一位交易者的方法：**只挑止损能放得很近的地方买，看错了马上认亏，看对了多拿一段时间**。他亏钱的单子平均亏 2%，赚钱的单子平均赚 14%，每赚一笔只亏三笔半——这笔账用 **R** 来算（R = 打到止损会亏掉的钱）。

这个仓库做的事：把口头描述的方法，逐条拆成**可编码、可验证、参数已定值**的规则，并用真实市场数据检验每一条是否成立。

**不是**照抄。每一条规则都做过实测对照，有 12 处实测结论与流行说法或原始理解相反，都记录在案。

---

## 核心逻辑

```
先定亏多少（止损） → 再倒推买多少（仓位） → 让同样的涨幅变成更大的 R
```

| 环节 | 关键参数 | 实测依据 |
|---|---|---|
| **止损宽度** | `s_max = min(ATR14(日)×0.5, ADR%/2, 5%)`<br>`s_min = max(0.5%, 3.0×ATR14(5m))` | 上限锚住"常态波动的一半"，下限锚住"3 根 5 分钟 K 线的噪音" |
| **仓位** | `仓位 = 账户 × 风险% ÷ s` | 单笔风险 0.5%，止损越窄买得越多 |
| **R 倍数** | `R = 涨幅 ÷ s` | 止损 2% 时，涨 25% = 12.5R；止损 1.5% 时 = 16.7R |
| **出场** | 分批卖 + 保本 + 均线跟踪 | 首批 R 门槛 3/5/12/15 四档进网格 |

**为什么"止损收紧"是配对决策**：保住同一个期望值，止损越窄需要的胜率越低——s=1.5% 只要 16.6% 胜率，s=3.0% 要 30.4%。这才是"止损超过 3% 就不做"的真实原因，不是 3% 有魔法。

## 加密特化版

仓库内有一个子目录专门做加密落地：**[Martin Strategy · Crypto](Martin%20Strategy-%20Crypto/)**

它在上层规格的基础上只改 4 处（交易时段、资金费率、插针缓冲、杠杆运维），其余全部继承，并附可直接被引擎读取的 `config.yaml`。三个值得一看的实测结论：

- **最活跃的时段 V 型反转胜率最低**：UTC 14:00 活跃度 1.95x 但上涨占比仅 40%；最冷的 UTC 10:00 有 62%
- **资金费率是真实成本**：BTC 年化 5.3%，持 7 天 = 0.069R（对 E[R]=0.30 是 23% 侵蚀）
- **插针风险被高估**：主流币 5m 下影 >0.5% 的 K 线只占 0.1–1.0%，不需要加缓冲

## 有实测支撑的关键结论

全部基于币安永续合约真实数据（2019-09 起，最长 6.5 年样本）。

| 结论 | 数据 |
|---|---|
| **回调买法 >> 突破买法** | 10 日后中位 +14.94% / 91% 上涨 vs +1.14% / 56%（同批 20 标的） |
| **逐年看更明显** | 回调买法 7 年全部为正，突破买法 2022 / 2025 两年为负 |
| **"弹得越快股票越强"是最强信号** | 收复均线 1 日 → +20.45% / 98% 上涨；12 日 → −5.02% / 15% 上涨 |
| **位置晚是负收益** | 位置早 +4.84%（66% 上涨）vs 位置晚 −3.14%（45%） |
| **"先涨过再回踩"是硬规则** | 上穿后回踩 −0.12% vs 直接跌到 −5.20%（均线支撑，差 5.1pp） |
| **止损宽度必须用分钟级算** | 同一规则：日线口径 P50=8.08%（只有 12% 能过 3%），5m 口径 P50=1.15%（82% 能过） |
